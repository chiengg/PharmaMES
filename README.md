# 化工行业 MES 管理系统（PharmaMES）

高保真前端原型 · 精细化工 / 制药行业制造执行系统（MES）

- **在线演示**：https://chiengg.github.io/PharmaMES/
- **系统讲解文档（对外演示）**：[系统讲解文档.md](系统讲解文档.md)
- **产品需求文档（PRD）**：`精细化工行业MES系统PRD文档.docx`

## 功能概览

覆盖 **生产 / 质量 / 物料 / 设备 / 合规 / 数据** 六大域，35 个核心页面，打通
`计划 → 准备 → 工单 → 执行 → 批次 → 放行 → eBR` 全链路。

核心亮点：

- 多工厂数据隔离（组织 × 角色 双层权限）
- 字段级权限（Q-07）
- AI 投料推荐（Q-03）
- PDA 现场采集与离线续传（Q-01 / Q-04）
- eBR 电子批记录归档（Q-05）
- LIMS / ERP / WMS 系统集成联调（Q-06 / FR-INT）

## 技术形态

纯静态前端（HTML / CSS / 原生 JS），无后端依赖，可直接以静态站点部署。

## 本地预览

```bash
# 在项目根目录启动静态服务
python3 -m http.server 8777
# 浏览器打开 http://127.0.0.1:8777/
```

## 目录说明

- `index.html` — 系统门户入口（含 MES_ROUTES 动态路由）
- `sidebar.js` / `mes-nav.js` — 侧边栏导航与路由
- `plant.js` / `role.js` — 多工厂隔离 / 字段级权限
- 其余 `*.html` — 各业务页面原型
